# GS_Python_2026
#  Objetivo da atividade
Desenvolver um programa em Python que simule um sistema básico de
controle de missão espacial.<br><br>
O programa deverá:<br>
• armazenar dados simulados de uma missão;<br>
• analisar diferentes ciclos de monitoramento;<br>
• gerar alertas automáticos;<br>
• calcular o nível de risco de cada ciclo;<br>
• identificar a tendência da missão;<br>
• indicar qual área da missão foi mais afetada;<br>
• exibir um relatório final no terminal;<br>
• documentar o projeto em um repositório no GitHub.
